  • Discord login and a Discord bot (/fair, /parlay, /log); automated grading from official box scores; deployed on Fly.io.

Reputater AI Review Platform

A Next.js 16 / React 19 web app, a C# .NET 10 API, and a cross-platform Expo / React Native mobile app — each submitted review is analyzed by OpenAI GPT-4o for sentiment, then published or rejected with a notification.

Paylogic Published Shopify App
A Shopify App Store checkout app that hides, renames & reorders payment methods, built as the replacement for retired Shopify Scripts.

Payment-method rules are evaluated on every cart by a Rust → WebAssembly Shopify Function, with an embedded merchant admin built on React Router 7, TypeScript, and Vite.

  • One-click Scripts importer and visual rule builder with 18 conditions (cart total, country & ZIP, customer & product tags, lifetime spend, risk score) combined through OR groups.
  • Risk-gated rule that hides Cash on Delivery using Shopify's order-risk signals, a capability Scripts never had.
  • Type-safe Admin API access via Node.js, Prisma ORM & Shopify GraphQL codegen.
  • Tiered subscription billing ($1.99–$9.99/mo, annual discount, 3-day trial), plan-gated rules, and config versioning & rollback (50-snapshot history).
  • Pre-caches customer/product tags into metafields via webhooks to optimize checkout latency.
  • Handles GDPR privacy/redaction webhooks; deployed to Fly.io with Docker and automated Prisma migrations.

Counterline Published Shopify App

Jazz Guitar Course Interactive Course
A complete beginner-to-professional jazz guitar course, generated and fact-checked by a music-theory engine.

15 modules and 80 lessons, from reading and fretboard basics through voicings, comping, the blues, bebop language, reharmonization, chord melody, and professional skills. Every lesson has playable notation and tab with audio, generated chord diagrams and fretboard maps, a practice assignment, and a quiz.

  • A Python music-theory engine is the single source of truth: 8,800+ chord voicings and every theory table are generated, then verified by playing the frets back through a fretboard model.
  • 439 notated examples are parsed by alphaTab at build time; the build checks every bar's rhythm and that claimed chord tones really fit the chord.
  • Interactive tools: chord dictionary with a voice-leading assistant, scale finder, fretboard & ear trainers, and a metronome.
  • 258 pytest tests pin the engine to textbook theory, and a headless-browser smoke test opens all 107 pages.
